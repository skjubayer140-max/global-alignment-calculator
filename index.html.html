What is global alignment?

Global alignment compares two sequences from beginning to end and finds the best overall alignment. It lines up matching letters and adds gaps (-) where one sequence needs a pause.

Scoring parameters

Set these first. They decide how every cell of the matrix is calculated.

How the algorithm works

Four simple steps.

  1. 1

    Initialize

    Make a grid. Fill the first row and column with 0, then −2, −4, … (one gap penalty per step).
    0−2−4−2−4
  2. 2

    Fill the matrix

    For each cell, try a diagonal move (match or mismatch), a move down (gap) and a move right (gap). Keep the highest score.
    ↖↑←?
  3. 3

    Read the score

    The bottom-right cell holds the best total score for aligning both full sequences.
    ★
  4. 4

    Trace back

    Walk from the bottom-right to the top-left, following the moves that produced each score. Reverse the result to get the alignment.
    ★↖↖

Algorithm formula

F(i,j) = max(
  F(i-1,j-1) + score,
  F(i-1,j) + gap,
  F(i,j-1) + gap
)
  • F(i,j): the best score for aligning the first j letters of Sequence 1 with the first i letters of Sequence 2.
  • F(i-1,j-1) + score: take the diagonal cell and add the match score or mismatch penalty.
  • F(i-1,j) + gap: take the cell above and add the gap penalty (a gap in Sequence 1).
  • F(i,j-1) + gap: take the cell to the left and add the gap penalty (a gap in Sequence 2).
  • max: keep the largest of the three values.
